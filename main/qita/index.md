::: details 建站起源

- 最初是不懂编程的，也没关注过。
- 偶尔一次在玩一个网页文字游戏，那个网站可以让我们按照指定格式创作自己的文字游戏，然后在线玩，也可以玩别人制作的。
- 其实类似于if,switch和一些简单的数值计算，然后当时的我沉迷其中不可自拔。
- 直到某一次，看到有人评价，说这个就是简化版的js，好多js的命令都不能用。
- 然后我就搜索js，开始研究，后来又接触了php。
- 哪里研究的？当然是菜鸟教程，因为我编程很菜。
- 2021年初次建站，直到如今。

:::
