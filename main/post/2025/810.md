# termux常用命令

 ```bash
 搜索包 pkg search (软件名)
  安装包 pkg install (软件名)
  卸载包 pkg uninstall (软件名)
  升级软件包 pkg upgrade
  更新包列表 pkg update
  列出包列表 pkg list-all
  列出已安装包列表 pkg list-installed

  修改欢迎语 vim $PREFIX/etc/motd
  获取存储权限 termux-setup-storage
  修改源 termux-change-repo

  设置脚本权限 chmod 755 hello.sh
  运行脚本 ./hello.sh

  查看系统占用 top 按q推出
  查看内存    free -m
  查看当前路径 pwd
  查看当前路径文件 ls -a

  检测HTTP版本 curl -I --http3 网址
  检测开放端口  nmap -p 1-1024 网址
  测并发(简单)  ab -n 500 -c 80 网址//并发80，共500请求
  测并发(高级)  wrk -t2 -c100 -d30s --latency 地址//并发100，开2个进程，持续30秒
  ```
