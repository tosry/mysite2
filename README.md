# 个人项目说明

这是一个个人技术博客项目，主要用于记录和分享技术文章、学习笔记以及项目实践。

## 项目结构

项目主要分为以下几个部分：

- **博客文章**：包含技术文章、学习笔记等，涵盖前端开发、后端开发、服务器配置、编程技巧等多个方面。
- **书籍资料**：包含中医等传统文化相关的内容，如《四圣心源》《黄帝内经》等。
- **网页主题**：使用 VitePress 构建，包含自定义布局和样式。
- **其他资源**：包括静态资源、配置文件、许可证等。

## 技术栈

- 使用 **VitePress** 作为静态网站生成器。
- 采用 **Markdown** 格式编写文档和文章。
- 部分技术实现涉及 **JavaScript**、**PHP**、**Shell** 脚本等语言。

## 功能特点

- 文章分类清晰，涵盖技术、中医等多个主题。
- 支持代码部署、边缘计算、服务器配置等高级功能。
- 提供丰富的技术实践案例，如自动寻路、防火墙配置、限速设置等。

## 使用说明

1. **本地运行**：确保安装 Node.js 环境，使用 `npm run dev` 启动本地开发服务器。
2. **构建站点**：使用 `npm run build` 构建静态站点。
3. **部署**：可部署到任意静态服务器，支持 Cloudflare EdgeOne、Nginx 等部署方式。
